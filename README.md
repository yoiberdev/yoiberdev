Full-stack developer in Lima, Peru. I build systems that keep working when nobody is watching. One
carries live video from cameras on vessels over a satellite link that drops several times a day;
another tells a company which of its technicians are on board right now. Backend in Python, Node and
Java, interfaces in React and TypeScript, and Linux machines a long way from any keyboard.

### Side projects
